# Rice CachyOS - Futurista & Zero-UI (v1.0)

Entorno de escritorio minimalista, fluido y enfocado en desarrollo de alto rendimiento, optimizado para laboratorios, hackatones y uso diario multitarea en CachyOS.

## 🚀 Características Principales
- **Gestión Dinámica de Ventanas:** Hyprland con *tiling* automático, esquinas redondeadas pronunciadas, bordes dinámicos y animaciones ultra fluidas.
- **Interfaz Oculta / Zero-UI:** Diseñado para mantener la pantalla limpia de distracciones, invocando elementos solo cuando se necesitan.
- **Paleta de Colores Dinámica:** Integración con `Matugen` para adaptar los colores del sistema automáticamente según el fondo de pantalla actual.
- **Ventanas Fantasma (Scratchpads):** Acceso instantáneo a herramientas frecuentes mediante `Pyprland` con efectos de caída y desvanecimiento.

## 🛠️ Stack Tecnológico
- **Compositor:** Hyprland (Wayland)
- **Gestor de Colores:** Matugen + swww
- **Terminal:** Kitty
- **Control de Ventanas Flotantes:** Pyprland
- **Fuente:** JetBrainsMono Nerd Font
